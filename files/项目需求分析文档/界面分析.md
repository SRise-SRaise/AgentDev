# 基于 Agent 的 Web 高级编程管理平台——详细界面设计文档

> 版本：V1.0  
> 课程对象：Web 高级编程  
> 系统定位：面向单门课程的教学闭环管理、实验评测和大作业 Agent 智能评测平台

---

## 1. 系统总体定位

本系统不是传统的“多课程教务管理系统”，而是围绕《Web 高级编程》这一门课程，完成如下教学闭环：

```text
课程大纲导入
→ 课程评分参数确认
→ 作业成绩导入
→ 实验成绩自动汇总
→ 大作业 Agent 智能评测
→ 总成绩计算
→ 达成度计算
→ 成绩明细表导出
→ 课程质量评价资料汇编生成
```

系统整体分为教师端和学生端。

```text
教师端
├── Web 高级编程课程闭环管理
├── 实验模块
│   ├── Vue 实验
│   └── Python 实验
└── 大作业管理模块

学生端
├── 实验模块
├── 大作业模块
└── 课程查看模块
```

---

## 2. 用户角色设计

### 2.1 教师

教师负责课程参数确认、实验发布、测试用例配置、大作业发布、成绩导入、成绩复核、报表导出和课程质量评价资料生成。

### 2.2 学生

学生负责查看实验任务、提交代码或项目 ZIP、查看实验运行结果、查看大作业 Agent 评测报告、查看个人成绩。

### 2.3 管理员

管理员只负责用户、班级、权限等基础维护，不参与具体课程评价流程。若项目规模较小，可以将管理员能力合并到教师账号中。

## 3.1.5 导入课程大纲

### 页面作用

导入课程大纲不是为了管理课程列表，而是为了提取课程评价所需参数。

系统应从课程大纲中提取：

| 提取内容 | 系统用途 |
|---|---|
| 课程名称、学时、学分 | 报表抬头、课程档案 |
| 课程目标 | 达成度计算和课程质量评价 |
| 考核方式 | 作业、实验、大作业/考试评分项 |
| 成绩权重 | 计算总成绩 |
| 实验安排 | 与实验模块任务进行匹配 |
| 达成度评价方法 | 生成达成度计算规则 |
| 课程目标支撑关系 | 生成达成度分析表 |

### 交互流程

```text
点击【导入课程大纲】
→ 上传 Word / PDF
→ 系统解析课程参数
→ 显示解析结果
→ 教师确认或修改
→ 保存为课程闭环参数
```

### 解析结果确认界面

```text
课程基本信息
├── 课程名称
├── 学分
├── 学时
└── 适用专业

课程目标
├── 课程目标 1
├── 课程目标 2
└── 支撑毕业要求

评分项
├── 作业：30 分
├── 实验：20 分
└── 大作业/考试：50 分

实验安排
├── 实验一
├── 实验二
├── 实验三
└── 实验四
```

### 关键设计

系统默认把“考试/期末”映射为“大作业成绩”，因为本项目设计中大作业承担综合考核功能。

默认成绩结构建议：

| 成绩项 | 分值 | 来源 | 说明 |
|---|---:|---|---|
| 作业成绩 | 30 | 教师手动导入 | 只支持手动导入 |
| 实验成绩 | 20 | 实验模块自动汇总 | 所有实验平均分折算 |
| 大作业成绩 | 50 | 大作业模块 | Agent 评测 + 教师复核 |
| 总成绩 | 100 | 系统计算 | 作业 + 实验 + 大作业 |

## 3.1.6 学生成绩列表

### 页面主表

| 字段 | 说明 |
|---|---|
| 序号 | 自动生成 |
| 学号 | 学生唯一编号 |
| 姓名 | 学生姓名 |
| 班级 | 所属班级 |
| 作业成绩 / 30 | 教师导入 |
| 实验成绩 / 20 | 实验模块同步 |
| 大作业成绩 / 50 | 大作业模块同步 |
| 总成绩 / 100 | 系统自动计算 |
| 课程目标 1 达成状态 | 达成 / 未达成 |
| 课程目标 2 达成状态 | 达成 / 未达成 |
| 操作 | 查看详情 |

### 成绩计算逻辑

```text
实验原始平均分 = 所有实验成绩之和 / 实验次数

实验成绩 / 20 = 实验原始平均分 × 20%

总成绩 = 作业成绩 + 实验成绩 + 大作业成绩
```

说明：

如果实验模块内部每个实验按 100 分制保存，则课程闭环管理页面需要将平均分折算为 20 分制。

```text
实验成绩 / 20 = 平均实验分 / 100 × 20
```

大作业如果内部按 100 分制保存，则折算为 50 分制。

```text
大作业成绩 / 50 = 大作业最终分 / 100 × 50
```

## 3.1.8 同步实验成绩

### 页面入口

```text
Web 高级编程课程闭环管理
└── [同步实验成绩]
```

### 数据来源

```text
实验模块
├── Vue 实验成绩
└── Python 实验成绩
```

### 同步规则

```text
1. 读取每名学生所有已发布实验的最终成绩
2. 计算平均实验分
3. 折算为课程成绩中的实验成绩
4. 写入学生成绩列表
```

### 特殊情况

| 情况 | 处理方式 |
|---|---|
| 学生缺交某实验 | 该实验记 0 分或按教师设置处理 |
| 学生多次提交 | 默认取最高分或最后一次有效提交 |
| 教师手动复核 | 以教师复核分为最终分 |
| 实验未结束 | 可以选择暂不同步 |

## 3.1.10 达成度计算

### 页面作用

达成度计算用于判断课程目标是否达成，不只是展示总成绩。

### 简化版计算方式

由于当前系统主要使用作业、实验、大作业三个成绩项，可以采用如下方式：

| 课程目标 | 支撑成绩项 |
|---|---|
| 课程目标 1 | 作业、大作业 |
| 课程目标 2 | 实验、大作业 |

默认目标分值分配：

| 成绩项 | 总分 | 课程目标 1 | 课程目标 2 |
|---|---:|---:|---:|
| 作业 | 30 | 30 | 0 |
| 实验 | 20 | 0 | 20 |
| 大作业 | 50 | 20 | 30 |
| 合计 | 100 | 50 | 50 |

学生个人课程目标得分：

```text
课程目标 1 得分 = 作业成绩 + 大作业成绩 × 20 / 50
课程目标 2 得分 = 实验成绩 + 大作业成绩 × 30 / 50
```

课程目标达成判断：

```text
课程目标 1 达成 = 课程目标 1 得分 >= 课程目标 1 期望分值
课程目标 2 达成 = 课程目标 2 得分 >= 课程目标 2 期望分值
```

班级课程目标达成度：

```text
课程目标达成度 = 达到该课程目标期望分值的学生人数 / 学生总人数
```

### 页面展示

| 课程目标 | 目标分值 | 期望分值 | 达成人数 | 总人数 | 达成度 | 状态 |
|---|---:|---:|---:|---:|---:|---|
| 课程目标 1 | 50 | 35 | 42 | 50 | 84% | 达成 |
| 课程目标 2 | 50 | 35 | 38 | 50 | 76% | 基本达成 |

## 6.3 Agent 能力边界

Agent 不直接决定最终成绩，而是给出：

```text
1. 项目结构分析
2. 运行结果分析
3. 截图结果分析
4. 初步评分
5. 扣分依据
6. 修改建议
7. 是否需要人工复核
```

最终成绩以教师复核分为准。

## 6.4 安全要求

学生上传 ZIP 和代码执行必须隔离处理：

```text
1. 限制 ZIP 文件大小
2. 校验文件类型
3. 防止 Zip Slip 路径穿越
4. 禁止危险文件类型
5. 在 Docker 沙箱中运行代码
6. 设置 CPU、内存、时间限制
7. 保存完整运行日志
```
